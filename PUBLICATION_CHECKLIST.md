# Publication checklist

- [x] Both original and byte-identical local copy were checked. The raw XLSX is ignored.
- [x] Exact allowlist covers derived CSV and selected QA summaries. Detailed source inventories and logs are ignored.
- [x] Census suppression and dash notation are preserved without reconstruction.
- [x] Institutional attribution and demonstration status are explicit.
- [x] Database URL is supplied through the environment. The example holds no credential.
- [x] Cite the official INS source for derived statistical aggregates.
- [ ] Confirm permission before distributing the original publisher XLSX.
- [ ] Review the staged file list and confirm license attribution before creating a public repository.
- [ ] Verify the PostgreSQL load against an authorised disposable local instance before advertising database runtime coverage.
